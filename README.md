# ZAP support for vscode

> **Docs:** [ZAP for VS Code](https://zap-proto.dev/docs/sdks) · part of the [ZAP Protocol](https://zap-proto.io)


Syntax highlighting and language support for ZAP schema files. ZAP is a fork of [Cap'n Proto](https://capnproto.org/) and stays wire- and library-compatible with it, so `.capnp` files are supported alongside `.zap`.

## Features
- Syntax Highlighting
- Bracket matching
- ZAP ID generator ( Ctrl+Shift+p -> GenerateCapnpID )


Built specially for @grimpy

## Installation
clone repo under `~/.vscode/extensions/vscode-zap`.
